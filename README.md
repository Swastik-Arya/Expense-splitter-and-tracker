# Expense-splitter-and-tracker
it is used to track you expenses and split you expenses among group on trip.

## Overview

Expense Splitter and Tracker is a C-based console application developed to manage and split expenses efficiently among multiple people.

The application allows users to record expenses, view all saved expenses, calculate individual shares, save data for future use, and reset records whenever required.

## Features

* Add new expenses
* View all recorded expenses
* Split expenses among multiple people
* Save expense data for future sessions
* Load previously saved expense records
* Reset all stored data
* Simple menu-driven interface

## Technologies Used

* C Programming
* File Handling
* Data Structures
* Console-Based User Interface

## How It Works

1. User enters expense details.
2. Expenses are stored in a file.
3. Users can view all expenses.
4. Total expenses can be split among a specified number of people.
5. Data remains available even after restarting the application.
6. Reset option clears all saved records.
